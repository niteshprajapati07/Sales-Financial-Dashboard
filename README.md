# 📊 Sales & Financial Performance Dashboard
## 📌 Project Overview

This project is part of **Task 4: Dashboard Design** and focuses on creating an interactive and business-oriented dashboard using **Microsoft Power BI**.

The dashboard provides an overview of sales performance, profitability, growth, regional performance, products, customer segments, and financial metrics. Interactive slicers and visualizations allow business stakeholders to explore the data and identify important trends and insights.

---

## 🎯 Objective

The objective of this project is to design an **interactive dashboard for business stakeholders** that helps them:

- Monitor sales performance
- Analyze profitability
- Track sales growth
- Compare actual sales with budget
- Analyze regional and departmental performance
- Understand customer segment performance
- Identify top-performing products
- Make data-driven business decisions

---

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Microsoft PowerPoint** – Dashboard summary presentation
- **CSV Dataset** – Sales and Financial data

---

## 📂 Dataset

The project uses a **Sales_Financial dataset** containing sales, financial, product, regional, and customer-related information.

### Dataset Columns

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| Date | Order/transaction date |
| Financial_Year | Financial year |
| Quarter | Financial quarter |
| Month | Month of transaction |
| Region | Sales region |
| Department | Department |
| Product | Product name |
| Customer_Segment | Customer segment |
| Salesperson | Salesperson |
| Units_Sold | Number of units sold |
| Sales_Revenue | Revenue generated from sales |
| COGS | Cost of Goods Sold |
| Gross_Profit | Gross profit |
| Operating_Expenses | Operating expenses |
| Net_Profit | Net profit |
| Budget_Sales | Budgeted sales |
| Sales_Variance | Difference between actual and budget sales |
| Profit_Margin_Percent | Profit margin percentage |
| Growth_Percent | Sales growth percentage |
| Currency | Currency used for financial values |

## 📊 Dashboard Features

### 🔹 KPI Cards

The dashboard includes key performance indicators such as:

- **Total Sales Revenue**
- **Total Net Profit**
- **Profit Margin %**
- **Sales Growth %**
- **Sales Variance**
- **Total Units Sold**

These KPIs provide a quick overview of the overall business performance.

---

### 🔹 Time-Series Analysis

A **Sales & Net Profit Over Time** visualization is included to analyze changes in sales and profitability across different dates and periods.

This helps identify:

- Sales trends
- Profit trends
- Growth patterns
- Periods of strong or weak performance

---

### 🔹 Regional Analysis

The dashboard includes **Sales Revenue by Region** to compare sales performance across different geographical regions.

This helps identify:

- Top-performing regions
- Low-performing regions
- Regional sales opportunities

---

### 🔹 Department Analysis

Sales performance can be analyzed across different departments to understand which departments contribute most to overall revenue.

---

### 🔹 Product Analysis

Product-level analysis helps identify:

- Top-performing products
- Products generating high revenue
- Products contributing to profitability

---

### 🔹 Customer Segment Analysis

The dashboard provides sales analysis by customer segment, helping understand the contribution of different customer groups.

---

### 🔹 Sales vs Budget

Actual sales are compared with budgeted sales to understand:

- Budget achievement
- Sales variance
- Overall performance against targets

---
